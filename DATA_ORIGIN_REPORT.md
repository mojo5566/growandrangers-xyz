### Key Findings

- **100% of codes (12/12) are AI Generated** — zero from any real source
- All reward items (Mutation Shards, Pet Growth Potions, Double Harvest Boosts, etc.) are AI-invented
- All event names (Spring seasonal, Gardening Week, Festival milestone) are fabricated
- Code naming follows detectable AI patterns: seasonal keywords, leetspeak suffixes, game acronym prefixes
- Expiration dates are plausible for their seasonal themes but have no real basis
- The file structure (`CodesPageData` interface) is well-organized and production-ready — only the data values themselves are AI-generated

### AI Generation Patterns Observed

| Pattern | Example | Occurrences |
|---------|---------|-------------|
| Seasonal keyword | SPRING26, WINTER_CROP, SUMMER_SUN, AUTUMN_LEAF | 4 |
| Game acronym prefix | GAG_SPRING26 | 1 |
| Leetspeak suffix | SEEDS_4ALL | 1 |

| Generic lifestyle | FARM_LIFE, GARDEN_FEST | 2 |
| Numbered series | MUTA_WAVE3 | 1 |
| Holiday naming | HOLIDAY_2025, SPOOKY_FARM | 2 |

### Recommendation

If this project is for a real game, all 12 codes must be replaced with codes sourced from official developer channels. If this is a demo/concept project, add a clear "Example Codes" label to the page.
